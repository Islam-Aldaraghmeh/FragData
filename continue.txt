COMMANDS (run from the repository root)
---------------------------------------
Step 1 - three parallel processes, 4 torch threads each:

  .venv/bin/python -m intensity_lab.experiments gnn_agg_mean,gnn_loss_cos 4 > logs_reg1.txt 2>&1 &
  .venv/bin/python -m intensity_lab.experiments gnn_graph_only,gnn_original_inputs 4 > logs_reg2.txt 2>&1 &
  .venv/bin/python -m intensity_lab.experiments gnn_context,gnn_reg,gnn_deeper 4 > logs_reg3.txt 2>&1 &
  grep DONE logs_reg*.txt          # each finished run prints one DONE line

Step 2/3 - find the final name, then train its group (replace gnn if another wins):

  .venv/bin/python -c "
from intensity_lab.pipeline import load_data
from intensity_lab import experiments as EXP
from intensity_lab.train import train
from intensity_lab.metrics import evaluate_bags, summarize
d = load_data(verbose=False); V = d.splits['molecule']['val']
s = {n: summarize(evaluate_bags(d.fs, V, train(d.fs, d.splits['molecule'], EXP.get(n), d.data_key(), verbose=False).predict(d.fs, V))).iloc[0]['cos'] for n in EXP.FINAL_CANDIDATES}
print(s, '->', EXP.pick_final(s))"

  .venv/bin/python -m intensity_lab.experiments final 4 gnn > logs_final.txt 2>&1 &

PAUSING IS SAFE
---------------
* Finished runs are never retrained (file name = config hash).
* Every epoch writes <run>.partial.pt; interrupting and re-running the same
  command resumes after the last finished epoch with identical results
  (tested with kill -9).
* "Run All" in the notebook trains anything missing, so steps 1-3 can also be
  done just by running the notebook (slower: one model at a time).

IMPORTANT NOTES
---------------
* Do not edit a config in intensity_lab/experiments.py without expecting it to
  retrain: its hash changes. Adding new configs is fine.
* The notebook is GENERATED from intensity_lab/tools/notebook_cells.py. Edit the
  cells there (or edit the notebook directly and stop using the builder).
* Use DEVICE = "cpu" (benchmarked faster than MPS here).
* Big generated folders you may want to keep out of git: data/agentic_cache/,
  results/experiment_1_agentic/runs/ (I did not modify .gitignore).
* Full findings so far: report.md
